# Materiales del emprendimiento

Esta carpeta se reserva para logo, fotos de productos y trabajos y otros materiales reales que entregue el negocio. Actualmente no hay materiales de marca recibidos.

Al recibir un archivo registrar origen, uso autorizado y versión en el estado del proyecto. Conservar originales y generar versiones optimizadas solo durante una etapa autorizada. No colocar credenciales, documentos personales o diseños privados de clientes aquí.

Los diseños enviados por clientes se atienden por WhatsApp y no forman parte de los recursos públicos de la web. Los datos de muestra usados para revisar un diseño no deben publicarse como reales.
